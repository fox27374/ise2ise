ise2ise

Migrate Cisco ISE configuration between two independent deployments.

TLS certificate verification is OFF. Connections to ISE are encrypted but the certificate is not checked, so this cannot detect an interposed server. That is the default because ISE ships a self-signed certificate. Restart with -verify-tls once the deployment presents a certificate your machine trusts.

Network device CSV translation

    
Translate a Cisco ISE network device CSV export into the column layout of another ISE deployment.


    

      These CSVs contain plaintext credentials.
      ISE's network device export carries RADIUS and TACACS shared secrets, SNMP auth/privacy
      passwords, TrustSec device passwords and EXEC/enable passwords in the clear. Keep the files
      on trusted storage, never commit them, and delete both the exports and the translated result
      once the import is done. Nothing is written to disk by this tool — upload, translation and
      download all happen in memory.
    


    

      
Workflow

      
    
        
  1. On the source ISE: Administration → Network Resources → Network Devices → Export. This CSV is the only route that carries the secrets; the REST API masks them.

  2. On the target ISE: Administration → Network Resources → Network Devices → Import, click Generate a Template and download it. That template defines the target release's column layout.
